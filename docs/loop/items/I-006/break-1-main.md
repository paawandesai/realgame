# I-006 break-1 (main breaker)

Built web release from loop/I-006 (2fe30c2); `node --test` 14/14; selftest 31/31 (3m56s); manual probes below.

## Blocking
None. The harness measures what the spec says and the scripted selftest passes.

## Should-fix
1. **Personas can read hidden state; the protocol does not enforce the information barrier.** `observe --truth` is available to any caller (daemon accepts it in every session), `<dir>/log.jsonl` (full truth per turn) and `session.json` sit next to `shots/`, and the persona agent runs in the repo checkout (source, docs/loop backlog, bars). panel.md says "no source code, no bars" but gives no mechanism (separate cwd, wrapper, `--truth` only when `PANEL_SELFTEST=1`). Fix: refuse `--truth` unless selftest/runner env; write log.jsonl outside the persona-visible dir (or a runner-only dir); tell the runner to spawn personas from an empty cwd with only the CLI path and the persona block.
2. **B8 `minutes_played` is gameable by idling.** Probe: `act wait 10000` x90 yields 15 panel minutes with no play; `score` then gives `B8.pass=true`. Fix: count only minutes with input other than `wait` (or cap idle waits per window), and require `turns` or acts/min above a floor.
3. **`score` ignores run quality and harness settings.** Probe with five valid results: qa `throttle:1`, `panics:3`, `stopped_because:"error"`, `turns:9` still gives B4/B5/B8 all `pass:true`. Fix: reject or fail the panel when qa throttle != 4, any persona throttle differs from its default without an `--allow-throttle`, panics > 0, `stopped_because:"error"`, or turns below a minimum.
4. **Throttle effect is never verified.** Session records `cdp_throttle_rate`, but nothing shows the game slowed down. Probe: qa (4x) got about 3.5 frames/s over a 10 s wait, 9yo (1x) got about 3 frames/s over 5 s: the software GPU dominates, so the CDP CPU throttle changes little visible behavior in the cloud. B4 "qa on a slow laptop" is therefore not really exercised. Fix: log a page-side CPU benchmark (fixed JS loop, `performance.now`) at start for each session into session.json, and have `score` check the qa/9yo ratio is > 2.
5. **time_to_move cannot be met by a natural input in the cloud.** Probe: `key w 1500` moved exactly 0.5 m (spawn z 18 -> 17.5), which is not "> 0.5", so `time_to_move_s` stayed null; the selftest passes only because it retries up to 6000 ms. A child tapping `w` (default 100 ms) never registers. Game motion is frame-clamped, so panel seconds and game seconds diverge (documented, but the B4 10 s limit is then judged on cloud slowness, not on the game). Fix: define ttm on key-hold panel time of the first act containing a movement key that produced any positive displacement (or scale by measured game-seconds per panel-second), and state the choice in panel.md.
6. **`time_to_cast_s` differs from the spec's definition.** Spec: casts rose and an object's chemistry changed. Implementation (`measure.mjs landed()`): impacts rose plus a result caption. A cast at a target with a result caption but no chemistry change (for example Fire at an already burning bush, or a caption-only spell effect) would count; a cast that changes chemistry but writes no new caption would not. Sky and ground casts are correctly excluded (probed: casts 1..6 with impacts rising and no result caption, ttc stayed null). Fix: also require a `chem` diff between samples, or update the spec and doc to the caption rule and say why.
7. **No negative control for "a broken game".** Selftest only runs against a healthy build. If the game freezes, `settle()`/`until()` time out silently (3 to 4 s wall) and acts still return `ok:true`; `observe` never flags a frozen `frame` counter or a black screenshot. The harness reports ttm/ttc null (bars fail), but a broken game that does move/cast yet renders nothing is invisible to everything but the persona. Fix: add a selftest case against a stubbed/broken page (no frames, or canvas hidden) and have `observe` expose a `frame_advanced:false` warning (derived from truth, not shown in the persona view as game state, only as `stalled:true`).

## Nit
- `report` takes `model` from the answer or `--model`; nothing checks qa used opus (config routing). A persona can also set its own `stopped_because` to `blocked`.
- `report` can run before `stop` (no stop entry): minutes_played then equals last act, and the daemon keeps going so later acts are not in result.json.
- `.json`, `.png` have no MIME entry in the static server (octet-stream); fine today, fragile if the client adds a JSON asset.
- Idle exit after 60 min of no commands kills the browser silently; `observe` then fails with ECONNREFUSED text rather than a harness error naming the cause.
- panel.md says `time_to_cast_s` sky cast "does not count" but a persona's first real cast in the selftest landed at 46 s panel time only because of selftest waiting; worth a note that selftest panel seconds are not representative.
- Selftest writes under `.loop-artifacts/` inside the repo; it is gitignored, ok.
